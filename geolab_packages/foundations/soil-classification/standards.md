# Standards Reference — Soil Classification

## ASTM D2487 — Standard Practice for Classification of Soils (USCS)

**Scope:** Laboratory classification of soils for engineering purposes using grain size distribution and Atterberg limits.

**Required Input Data:**
- Grain size distribution (D6913/D7928): percent passing each sieve, especially No. 4, No. 200
- Atterberg limits (D4318): liquid limit, plastic limit on minus No. 40 material
- Percent of organic matter if suspected

**Key Procedure:**
1. Determine percent coarser than No. 200 sieve
2. If > 50% retained → coarse-grained: determine gravel vs. sand (No. 4 boundary), then gradation (Cu, Cc) or plasticity of fines
3. If ≤ 50% retained → fine-grained: plot LL vs. PI on plasticity chart, check organic criterion
4. Assign group symbol and group name

**Important Notes:**
- Classification is based on material passing the 3-inch (75 mm) sieve; cobbles and boulders noted separately
- Organic criterion: LL oven-dried / LL not dried < 0.75
- Group name provides more detail than symbol (e.g., "Poorly graded sand with clay" vs. just "SP-SC")

## ASTM D2488 — Standard Practice for Description and Identification of Soils (Visual-Manual)

**Scope:** Field identification and description without laboratory testing. Results are estimates.

**Key Procedures:**
- Estimate grain size percentages visually
- Perform manual tests on fine-grained fraction: dilatancy, dry strength, toughness
- Describe: color, moisture, odor, consistency, cementation, structure
- Assign estimated group symbol

**Important Notes:**
- Preceded by "estimated" in reports to distinguish from D2487 laboratory classification
- Essential for field logging of borings and test pits
- Descriptions of structure (fissured, slickensided, laminated, blocky) are critical engineering information not captured in D2487

## ASTM D6913 — Standard Test Methods for Particle-Size Distribution (Gradation) of Soils Using Sieve Analysis

**Scope:** Grain size distribution for particles retained on the No. 200 sieve.

**Key Parameters:** Percent passing each sieve; D₁₀, D₃₀, D₆₀ for Cu and Cc calculation.

**Specimen Size:** Depends on maximum particle size. Min 300g for sands, up to 5000g+ for gravels.

## ASTM D7928 — Standard Test Method for Particle-Size Distribution of Fine-Grained Soils Using the Sedimentation (Hydrometer) Analysis

**Scope:** Grain size distribution for particles passing the No. 200 sieve, based on Stokes' law settling velocity.

**Key Assumptions:** Spherical particles, laminar flow (Re < 1), dilute suspension. Clay particles are not spherical — reported sizes are "equivalent spherical diameters."

## ASTM D4318 — Standard Test Methods for Liquid Limit, Plastic Limit, and Plasticity Index of Soils

**Scope:** Determination of Atterberg limits for classification and engineering correlations.

**Methods:**
- Liquid limit: Casagrande cup (Method A: multipoint, Method B: one-point) or fall cone
- Plastic limit: hand-rolling to 3.2 mm (1/8 in) thread

**Key Notes:**
- Performed on minus No. 40 sieve fraction
- Soil must not be oven-dried before testing (drying can permanently alter plasticity of some clays)
- Multipoint method (Method A) is preferred for classification purposes

## AASHTO M 145 — Standard Specification for Classification of Soils and Soil-Aggregate Mixtures for Highway Construction Purposes

**Scope:** Classification of soils for highway subgrade evaluation.

**Key Differences from USCS:**
- No. 200 sieve boundary for granular vs. silt-clay is 35% (not 50%)
- Uses Group Index (GI) for quality rating
- Classification proceeds left-to-right in table — first match is correct
- No dual symbols
- More focused on subgrade suitability than general engineering behavior
