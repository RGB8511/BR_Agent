# Standards Reference — Rock Classification

## ASTM D5878 — Standard Guides for Using Rock-Mass Classification Systems for Engineering Purposes

**Scope:** Guidance on applying RMR, Q-system, and other rock mass classification systems. Not a classification system itself — references the primary systems.

## ASTM D6032 — Standard Test Method for Determining Rock Quality Designation (RQD) of Rock Core

**Scope:** Standardized measurement of RQD from rock core.

**Key Requirements:**
- Core size: NX (54.7 mm) or larger preferred. NQ (47.6 mm) acceptable.
- Measure only intact, sound pieces ≥ 10 cm along centerline
- Do not count broken pieces caused by handling if the fracture surfaces are fresh and do not match natural discontinuity surfaces
- Record per run (typically 1.5 m or 5 ft), not averaged over entire borehole
- Immediately log core in field before handling damage occurs

## ASTM D5731 — Standard Test Method for Determination of the Point Load Strength Index of Rock and Application to Rock Strength Classification

**Scope:** Point load testing for rapid strength estimation.

**Test Configurations:**
- Diametral test (preferred for core): load perpendicular to core axis
- Axial test: load parallel to core axis
- Block/irregular lump test: for samples without regular geometry

**Key Requirements:**
- Minimum 10 valid tests per sample for reliable statistics
- Size correction to 50 mm equivalent diameter is mandatory
- Record failure mode (valid: splitting through both loading points; invalid: edge break, single contact failure)

## ASTM D2113 — Standard Practice for Rock Core Drilling and Sampling of Rock for Site Exploration

**Scope:** Rock coring procedures, core barrel types, and drilling fluid.

**Core Barrels:**
- Single tube: adequate only for massive, competent rock
- Double tube (swivel type): standard for most rock coring. Inner tube remains stationary while outer rotates.
- Triple tube: for soft, fractured, or friable rock. Split inner tube allows extraction without pushing core out.
- Wireline: for deep holes. Core barrel retrieved through drill string without pulling rods.

**Key Notes:**
- Core recovery (%) = (length of core recovered / length of core run) × 100
- Core recovery < RQD always (broken pieces < 10 cm contribute to recovery but not RQD)
- Core orientation techniques (scribing, acoustic televiewer) needed when discontinuity orientation matters for design

## ISRM Suggested Methods for Rock Characterization

**Scope:** International Society for Rock Mechanics suggested methods for:
- Quantitative description of discontinuities (1978, updated)
- Rock core logging
- Point load testing
- Weathering classification
- Joint roughness measurement

These are suggested methods (not mandatory standards) but widely adopted internationally and form the basis for most rock engineering classification work.
