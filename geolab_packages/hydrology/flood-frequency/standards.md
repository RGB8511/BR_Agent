# Standards Reference — Flood Frequency Analysis

## USGS Bulletin 17C (2019) — Guidelines for Determining Flood Flow Frequency
**Scope:** The US standard for flood frequency analysis using the Log-Pearson Type III distribution. Replaces Bulletin 17B (1982). Key updates: Expected Moments Algorithm (EMA) replaces method of moments, Multiple Grubbs-Beck (MGB) test for low outliers (PILFs), improved handling of historical/paleoflood information, and systematic/censored data. Weighted skew using generalized regional skew.

## FEMA — National Flood Insurance Program (NFIP)
**Scope:** Regulatory framework for flood insurance and floodplain management. 100-year (1% AEP) flood defines the Special Flood Hazard Area (SFHA) and Base Flood Elevation (BFE). Flood Insurance Studies (FIS) use Bulletin 17C methods for hydrologic analysis and HEC-RAS for hydraulic analysis.

## USACE EM 1110-2-1415 — Hydrologic Frequency Analysis
**Scope:** USACE guidance on frequency analysis for flood and low-flow studies. Consistent with Bulletin 17C. Additional guidance on confidence intervals, risk analysis, non-homogeneous records, and mixed-population floods.

## USGS StreamStats (Web Application)
**Scope:** Online tool providing streamflow statistics and regression-based flood quantile estimates for ungauged sites in the US. Drainage area delineation, basin characteristics, and state-specific regression equations. Includes prediction intervals.

## UK Flood Estimation Handbook (FEH)
**Scope:** UK standard for flood frequency analysis. Uses the Generalized Extreme Value (GEV) distribution fitted by L-moments. Regional frequency analysis with index flood method. Includes rainfall-runoff (ReFH2) and statistical methods.

## USGS Water Resources Investigations Reports (WRI) — State Regression Equations
**Scope:** State-by-state regional regression equations relating flood quantiles (Q_2 through Q_500) to watershed characteristics. Published as individual reports for each state or hydrologic region. Applied through StreamStats.

## Australian Rainfall and Runoff (ARR) — Book IV: Flood Estimation
**Scope:** Australian standard using LP-III with Bayesian parameter estimation (FLIKE software). Regional information used through Bayesian priors. Includes guidance on PMP/PMF estimation.
