# Standards Reference — UAS Photogrammetry

## ASPRS Positional Accuracy Standards for Digital Geospatial Data (2023)
**Scope:** Defines accuracy classes and reporting methodology for geospatial data including UAS-derived products. Horizontal and vertical accuracy classes tied to RMSE at check points. Replaces legacy NSSDA for modern mapping products.

## FAA 14 CFR Part 107 — Small Unmanned Aircraft Systems
**Scope:** US Federal Aviation Administration regulations for commercial UAS operations. Pilot certification (Remote Pilot Certificate), operating rules (400 ft AGL, VLOS, daylight), airspace authorization, waivers. Essential compliance requirement for any US commercial UAS survey operation.

## ASTM F3548 — Standard Specification for UAS Remote ID
**Scope:** Requirements for UAS Remote Identification broadcast. All UAS operating in US airspace must comply. Broadcasts operator location, UAS location, altitude, velocity, and identification.

## ASPRS Guidelines for UAS Mapping (2019)
**Scope:** Best practices for UAS-based photogrammetric mapping. Flight planning, GCP placement, image acquisition, processing, accuracy assessment, and deliverable specifications. Companion to the positional accuracy standards.

## ISO 19157 — Geographic Information — Data Quality
**Scope:** Framework for describing and evaluating quality of geographic datasets. Completeness, logical consistency, positional accuracy, temporal accuracy, and thematic accuracy. Applied to UAS-derived products for quality metadata.

## OGC GeoTIFF Standard
**Scope:** Standard for georeferenced raster imagery. Orthomosaics and DEMs from UAS processing are typically delivered as GeoTIFF. Supports multiple coordinate reference systems, data types, and compression. Universal interchange format for raster geospatial data.
