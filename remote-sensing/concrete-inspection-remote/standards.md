# Standards Reference — Remote Concrete Inspection

## ACI 201.1R — Guide for Conducting a Visual Inspection of Concrete in Service
**Scope:** ACI guide for systematic visual inspection of concrete structures. Defines deterioration types (cracking, scaling, spalling, efflorescence, corrosion, erosion, ASR), severity classification, inspection procedures, and documentation requirements. The baseline reference for concrete condition assessment that remote methods must match.

## FHWA-HIF-19-056 — Unmanned Aerial Systems for Bridge Inspection
**Scope:** FHWA guidance on using UAS for NBIS bridge inspection. Flight planning, camera/sensor selection, GSD requirements for Element-Level inspection, pilot certification, airspace requirements, data management, and integration with conventional inspection. Addresses regulatory (Part 107) and practical considerations.

## ASTM D4788 — Standard Test Method for Detecting Delaminations in Bridge Decks Using Infrared Thermography
**Scope:** Standard procedure for thermal IR detection of delaminations in concrete bridge decks. Survey conditions (weather, time of day), camera requirements, data collection procedure, and interpretation guidelines. Establishes minimum detectable delamination size and depth criteria.

## ASTM D6087 — Standard Test Method for Evaluating Asphalt-Covered Concrete Bridge Decks Using Ground Penetrating Radar
**Scope:** GPR procedure for evaluating concrete beneath asphalt overlay. Applicable to bare concrete with modified approach. Rebar detection, delamination identification, and deterioration mapping using high-frequency GPR antennas.

## ACI 224R — Control of Cracking in Concrete Structures
**Scope:** ACI committee report on cracking in concrete. Crack width limits, causes of cracking, design methods to control cracking, and repair approaches. Provides context for interpreting crack widths measured by remote inspection.

## FEMA 93 — Federal Guidelines for Dam Safety: Condition Assessment of Dams
**Scope:** FEMA guidelines for systematic condition assessment of dams including concrete structures. Inspection procedures, rating systems, documentation requirements, and frequency of inspection. Increasingly incorporating UAS and remote sensing methods.

## AASHTO Manual for Bridge Element Inspection (MBEI)
**Scope:** Element-level bridge inspection manual. Defines condition states (CS1–CS4) for each bridge element type including concrete decks, beams, piers, abutments, and culverts. Quantifies defect area in each condition state. Remote sensing data must map to these condition states for NBIS compliance.

## ACI 228.2R — Nondestructive Test Methods for Evaluation of Concrete in Structures
**Scope:** ACI guide to NDT methods for in-place concrete: GPR for rebar and delamination, impact-echo, ultrasonic pulse velocity, rebound hammer, and pullout tests. Provides context for integrating remote sensing results with contact-based NDT methods.
