# Standards Reference — Remote Fracture & Discontinuity Mapping

## ISRM Suggested Methods for Quantitative Description of Discontinuities in Rock Masses (1978)
**Scope:** International Society for Rock Mechanics standard for describing discontinuities. Defines parameters: orientation (dip/dip direction), spacing, persistence, roughness (JRC), wall strength, aperture, filling, seepage, and number of sets. The baseline that remote mapping results must match or exceed. Remote methods should report the same ISRM parameters.

## ASTM D5878 — Standard Guides for Using Rock-Mass Classification Systems for Engineering Purposes
**Scope:** Application of RMR, Q-system, and GSI classification systems. Remote discontinuity data (orientation, spacing, persistence, roughness) feeds directly into these systems. Guide covers field data collection requirements that remote sensing must satisfy.

## ISRM Suggested Method for Reporting Rock Discontinuity Survey Results (1981)
**Scope:** Standard format for presenting discontinuity survey data: stereonets, histograms of spacing and persistence, joint set statistics. Remote mapping output should follow these conventions for consistency with traditional surveys and geotechnical design input.

## Sturzenegger & Stead (2009) — Close-range terrestrial digital photogrammetry and terrestrial laser scanning for discontinuity characterization on rock cuts
**Scope:** Definitive comparison study of TLS and photogrammetry for discontinuity mapping. Establishes methodology for orientation extraction, discusses bias, accuracy, and practical considerations. Widely cited as the foundational methodology reference.

## Lato et al. (2009) — Optimization of LiDAR scanning and processing for automated structural evaluation of discontinuities in rock masses
**Scope:** Practical optimization of TLS survey parameters for geotechnical discontinuity mapping. Establishes relationships between scan distance, point density, and detectable feature size. Guidelines for scan planning and processing workflows.

## Riquelme et al. (2014) — A new approach for semi-automatic rock mass joints recognition from 3D point clouds
**Scope:** Describes the Discontinuity Set Extractor (DSE) algorithm for automatic joint set identification using kernel density estimation on normal vectors. Open-source implementation available. Validated against manual mapping at multiple sites.

## CloudCompare Documentation — Facets Plugin
**Scope:** Documentation for the open-source CloudCompare Facets plugin for planar facet extraction. Describes kd-tree subdivision, planarity filtering, and facet merging algorithms. Outputs dip/dip direction, facet area, and stereonet plots compatible with geotechnical analysis.
