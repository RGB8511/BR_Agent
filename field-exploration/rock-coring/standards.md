# Standards Reference — Rock Coring

## ASTM D2113 — Practice for Rock Core Drilling and Sampling of Rock for Site Exploration
**Scope:** Procedures for diamond core drilling including equipment selection (single, double, triple-tube barrels; wireline; conventional), drilling parameters, core handling, measurement of total core recovery and RQD, borehole deviation survey, and documentation. The primary standard for geotechnical rock coring.

## ASTM D6032 — Test Method for Determining Rock Quality Designation (RQD) of Rock Core
**Scope:** Detailed procedure for measuring RQD. Defines criteria for counting core pieces (≥ 100 mm sound rock), excluding mechanical breaks and weak/weathered zones, and calculating and reporting RQD per core run.

## ISRM Suggested Methods for Rock Characterization, Testing and Monitoring (2007)
**Scope:** Comprehensive ISRM compilation covering: core logging, discontinuity description, weathering classification, Schmidt hammer, point load test, block punch, shore hardness, slake durability, water content, porosity, density, and many others. International reference for standardized rock characterization.

## ISRM Suggested Method for the Quantitative Description of Discontinuities in Rock Masses (1978)
**Scope:** Standard descriptors for discontinuities: orientation (dip/dip direction), spacing, persistence, roughness (JRC), wall strength, aperture, seepage, number of sets, and block size. The foundation for systematic discontinuity characterization worldwide.

## DCDMA Standards — Diamond Core Drill Manufacturers Association
**Scope:** Standardized dimensions for wireline and conventional core barrels, drill rods, casing, and bits. Defines size designations (AQ, BQ, NQ, HQ, PQ) with exact dimensions. Ensures interchangeability between manufacturers.

## BS 5930 — Code of Practice for Ground Investigations
**Scope:** British standard covering all aspects of ground investigation including planning, drilling, sampling, in-situ testing, and reporting. Includes detailed rock and soil description standards widely used outside the UK.

## USACE EM 1110-1-1804 — Geotechnical Investigations
**Scope:** USACE manual for geotechnical exploration. Boring spacing by structure type, drilling requirements, sampling frequencies, in-situ testing, and reporting for USACE projects. Includes specific requirements for dam foundation investigations.
